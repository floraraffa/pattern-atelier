## Fail-safes

| Problem | Workaround for the take |
|---------|-------------------------|
| Hotspot miss | Use larger hotspots temporarily or keyboard/debug button in editor first |
| No AI | Stay on demoSeed; skip DESIGN prompt |
| No TTS | Assistant text only — still films fine |
| Board won’t snap | Place manually with handle; World Query optional for video |
